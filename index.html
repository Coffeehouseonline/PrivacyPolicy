Privacy Policy

Last Updated: March 2026

This Privacy Policy describes how the "Asset Sync" Chrome Extension handles user data. This extension is a personal utility tool designed for device recovery and hardware health monitoring.

1. Data Collection

  • Location Data: The extension collects GPS coordinates to allow the user to track their own device location.
  • System Metrics: The extension monitors CPU and Memory usage to provide hardware health insights.
  • User Identity: The extension uses the user's Google Email address to associate the data with the correct dashboard.

2. Data Usage

All captured data is transmitted directly and securely to the user's private Google Apps Script backend. We do not use this data for advertising, and we do not sell or share this data with any third parties.

3. Remote Code

This extension does not use, download, or execute any remotely hosted code. All logic is contained within the extension package.

4. Data Security

Data is transmitted via HTTPS encryption. Access to the collected data is restricted solely to the user who authorized the Google Apps Script deployment.

5. User Control

Users can stop all data collection immediately by uninstalling the extension or revoking permissions in the Chrome Extension settings.
